The project demonstrates a custom thread library with a preemptive scheduler through tests of thread creation, joining, mutexes, and read-write locks. It also includes a deadlock scenario to test thread synchronization and deadlock handling.

# How to run
* Requires a Linux environment, GCC and the standard C library
* Compile with gcc -Wall -Wextra -o thread_demo main.c thread.c, then run with ./thread_demo.
